# Study Planner

A single-file web app that builds a day-by-day study schedule. Harder subjects and closer exam dates
get more hours each day. Built with AI-assisted (vibe) coding using plain HTML, CSS and JavaScript.

## Run
Open `index.html` in any browser. No install needed.
